# H1 文档首行长标题用于验证装饰线始终以第一行文字居中而不会移动到整个多行标题的中间

## H2 长标题用于验证当标题文字跨越两行或者三行时装饰线仍然停留在第一行文字的垂直中心

### H3 长标题用于验证较小字号发生自动换行以后装饰线不会根据标题块总高度继续向下偏移

#### H4 长标题用于验证 Border 等带有标题伪元素的主题在编辑模式和阅读模式中得到一致结果

##### H5 长标题用于验证每级标题已有的装饰线高度和垂直微调仍然可以在第一行中心基础上独立生效

###### H6 长标题用于验证最小标题在窄栏中换行时装饰线位置稳定并且不会影响默认主题或 Canvas
