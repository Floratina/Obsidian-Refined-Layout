# Canary：压缩空行导航验证

> 本文件用于 Obsidian 手动验证，浏览器回归页面不能代替 Obsidian 宿主测试。
> 本文件有意包含连续空行，请不要运行会合并空行的格式化工具。

## 准备

1. 在 `canary` 分支运行 `npm run build`（不要加 `--no-sync`），然后在 Obsidian 中关闭再开启 Refined Layout。
2. 将本笔记复制到仓库中打开，使用实时预览模式。只按方向键时，文档内容不应发生任何改变。
3. 开启「正文」模块，分别试验空行高度 `0.45em`、`0.12em` 和 `0em`。其他排版参数保留原值，测试结束后恢复自己的空行高度。
4. 对照测试可以暂时关闭正文模块。标题后空行、代码块内空行也可能有独立设置，请分别关闭对应模块再比较。
5. 零高度下只检查逻辑位置能否逐行到达，不要求不同空行的光标在视觉上可区分。可以在一条空行短暂输入标记确认位置，再撤销。

## 宿主交互

- 折叠任一标题/代码块后移动：不能进入被折叠的隐藏行。
- 打开内部链接建议、标签建议或其他补全菜单：上下键应选择建议，不应移动笔记光标。
- 中文输入法正在选字时：上下键应由输入法处理。
- 已有普通选区时，不按 Shift 的上下键应保持原生收起选区的行为。
- 多光标导航由原生处理，本次修复不保证多光标逐一停留空行，但不能主动丢失选区。
- 在长笔记中滚动后、拆分编辑器后、切换实时预览/源码模式后重复测试。
- 修改空行高度或切换模块后立即返回编辑器测试，不应需要重开笔记。
- 阅读模式、Canvas、嵌入笔记和 DataviewJS 内容不应受本导航扩展影响。
