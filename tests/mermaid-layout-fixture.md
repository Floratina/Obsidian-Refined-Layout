# Mermaid 自适应宽度

请分别在 Live Preview 与阅读模式中检查本页。默认设置应为：纵向图最大宽度 55%、纵向判定宽高比 0.8、横向图最小宽度 450px（Obsidian 1.15 起停用此项）。已有配置不会自动改用新默认值，检查前请确认当前数值。

## 正文纵向图

下图应被识别为纵向图，按原始尺寸水平居中；只有超过内容区域宽度的 55% 时才缩小，不应放大节点和文字。

```mermaid
flowchart TD
    A[纵向步骤一] --> B[纵向步骤二]
    B --> C[纵向步骤三]
    C --> D[纵向步骤四]
    D --> E[纵向步骤五]
    E --> F[纵向步骤六]
```

## 正文横向图

原始宽高比大于 0.8 的图不应受到 55% 最大宽度约束。Obsidian 1.15 以下版本中，窗口不足 450px 时应允许横向滚动；1.15 及以上版本由原生自适应、缩放和平移处理。

```mermaid
flowchart LR
    A[横向起点] --> B[第二个较长节点] --> C[第三个较长节点] --> D[第四个较长节点] --> E[横向终点]
```

## Callout 内纵向图

> [!note] Callout Mermaid
> Callout 内的纵向图也应按原始尺寸居中，并受宽度上限约束。
>
> ```mermaid
> flowchart TD
>     A[Callout 一] --> B[Callout 二]
>     B --> C[Callout 三]
>     C --> D[Callout 四]
> ```

## 引用块内横向图

> 引用块内的横向图仍应使用横向规则。
>
> ```mermaid
> flowchart LR
>     A[Quote 一] --> B[Quote 二] --> C[Quote 三] --> D[Quote 四]
> ```

## 设置即时更新

1. 将当前模式的纵向图最大宽度从 55% 改为 65%，确认纵向图的宽度上限放宽、继续居中，但不会超过各自原始尺寸。
2. 将纵向判定宽高比调低，确认原始宽高比小于或等于新阈值的图才保留纵向标记；默认 0.8 时，800 × 1000 的图属于纵向图，900 × 1000 的图不属于纵向图。
3. Obsidian 1.15 以下版本中，修改横向图最小宽度，缩窄窗口并确认滚动边界随设置变化；1.15 及以上版本中，确认此项禁用并显示原因提示。
4. 关闭当前模式的 Mermaid 模块，确认所有插件宽度规则退出；重新启用后恢复。
